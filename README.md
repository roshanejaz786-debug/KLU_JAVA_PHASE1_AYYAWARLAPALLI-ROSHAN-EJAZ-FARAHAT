# KLU Java Phase 1 - Ayyawarlapalli, Roshan, Ejaz, Farahat

This repository contains Java practice exercises and example programs organized by day. Each folder represents a day of learning and includes small Java programs covering basic algorithms, loops, conditions, recursion, string operations, arrays, and number theory.

## Repository Structure

- `DAY 1/` - Basic arithmetic and number operations
- `DAY 2/` - Simple functions, loops, and conditional logic
- `DAY 3/` - Number theory and repetitions of basic problems
- `DAY 4/` - Pattern printing with stars and numbers
- `DAY 5/` - Advanced pattern programs and number patterns
- `DAY 6/` - Special number checks and mathematical properties
- `DAY 7/RECURSION/` - Recursive methods and recursion examples
- `DAY 8/` - Array operations, searching, and comparisons
- `DAY 9/` - Array manipulations and reversing techniques
- `DAY 10/` - String handling, word counting, character operations, and utility programs

## Highlights

- Over 80 Java programs demonstrating foundational programming concepts.
- Organized by topic and difficulty for easy learning.
- Includes simple examples of loops, functions, recursion, string processing, and array handling.

## How to Use

1. Open this folder in your preferred Java IDE or editor.
2. Compile and run individual `.java` files.
3. Explore the structure of each folder to follow the learning path.

## Example Commands

Compile a file:

```bash
javac "DAY 1/factor.java"
```

Run a file:

```bash
java -cp "DAY 1" factor
```

## Notes

- Use a consistent Java package or update file paths when moving files into a package structure.
- This collection is best for beginners practicing Java fundamentals.
